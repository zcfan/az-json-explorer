## 详细说明

AZ JSON Explorer 是一款在浏览器本地处理数据的 JSON 查看器，适合检查 API 响应、日志、测试数据和本地 JSON 文件。

它聚焦于三种常见工作流：

核心功能：
- 解析嵌套 JSON：把字符串中的对象或数组一键转换为可展开的树，同时保留原始字符串，随时切换原始/已解析视图。
- 独立视图：把树中的对象、数组或字符串单独打开到标签页。同一路径可以同时打开多个标签页；每个标签页分别保留自己的原始/已解析模式和搜索词。
- 历史记录：重新打开成功解析的手动输入和用户主动打开的文件，并恢复当时打开的独立标签页、原始/已解析模式和搜索词。

AZ JSON Explorer 可在识别到原始 JSON 页面后直接显示嵌入式查看器，也可在独立查看器中接收粘贴内容或打开本地文件。解析、树搜索和超长字符串搜索由 Web Worker 处理；树形区域只渲染当前视口附近的行，降低大型 JSON 对界面渲染的压力。

界面支持英语和简体中文，并自动跟随 Chrome 的界面语言；独立和嵌入式查看器的浅色与深色主题会自动跟随浏览器配色偏好。

历史记录仅保存成功解析的手动输入和用户主动打开的文件，数据保存在本地浏览器中，且不会自动清理；你可以随时手动删除。JSON 内容不会上传、同步或发送到第三方服务器。

本扩展不会：
- 提供树形节点的直接编辑，或将修改写回网页和本地文件。
- 将 JSON 内容上传、同步或发送到第三方服务器。

## 隐私与权限说明

AZ JSON Explorer 在浏览器本地处理 JSON，并仅在本地保存历史记录。扩展不会把 JSON 内容上传或同步到扩展开发者或第三方服务器，也不包含遥测或分析代码。

扩展的内容脚本会在 HTTP、HTTPS，以及用户已授权的 `file://` 页面上运行，以识别原始 JSON 并显示查看器。若要直接接管 `file://` JSON 页面，用户必须在 Chrome 扩展详情页中主动开启“允许访问文件网址”；使用查看器中的“打开文件”不需要这项权限。
